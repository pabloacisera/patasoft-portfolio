## CONTEXTO CRÍTICO DE NEGOCIO

### Modelo de precios de insumos (3 valores)
- `unitPrice` = precio de costo por unidad de stock (lo que pagás al proveedor por caja/frasco/etc.)
- `salePrice` = precio de venta por unidad de stock al cliente
- Precio unitario individual = `salePrice / unitsPerStock` (se calcula, no se almacena)
- `stockUnit` = unidad de compra (ej: "caja")
- `unitsPerStock` = cuántas unidades individuales contiene esa unidad de compra (ej: 15 jeringas por caja)
- `dispensingUnit` = unidad individual de venta/uso (ej: "jeringa")
- Cuando se usa un insumo en consulta: se descuenta del stock en unidades de `stockUnit`, pero se cobra al cliente por `dispensingUnit`. El sistema debe poder vender fracciones de stock.

### Flujo de consulta médica completo
1. Buscar mascota (por nombre o nombre del dueño) → si no existe, botón "+" abre formulario de creación inline
2. Completar datos clínicos (motivo, diagnóstico, tratamiento, peso, temperatura, observaciones)
3. Agregar procedimientos: buscar en `PriceItem`, seleccionar, definir cantidad
4. Agregar insumos: buscar en `Supply`, seleccionar, definir cuántas `dispensingUnit` se usan/venden → el sistema calcula cuántas `stockUnit` se descuentan del stock y el precio
5. Definir receta: para cada medicamento, indicar dosis, frecuencia, duración, si se vendió en clínica
6. Opcionalmente subir hasta 3 fotos nuevas de la mascota
7. Al confirmar: en una sola transacción atómica → guardar `MedicalRecord` + `Procedure[]` + `Prescription[]` + descontar stock de cada `Supply` usado + crear `Payment` en estado PENDING + generar PDF de receta + generar PDF de factura → ambos PDFs se suben a Cloudinary y se guardan en `Document`
8. Luego se abre el modal de pago para elegir el medio

### Flujo de pago
- **Efectivo**: el `Payment` pasa automáticamente a PAID, se crea `CashMovement` de INCOME
- **Transferencia**: requiere que `CompanyConfig.mpAlias` esté configurado. Muestra el alias en un modal. El pago queda PENDING hasta confirmación manual
- **QR MercadoPago**: requiere que `CompanyConfig.mpAccessToken` esté configurado. El backend llama a la API de MercadoPago Preferences y obtiene un `init_point` URL. El frontend genera un QR de esa URL usando la librería `qrcode.js`. Se muestra en modal con countdown de 5 minutos. Al expirar, el frontend hace una sola llamada al backend para verificar si el pago se procesó (el backend consulta el estado en MP por `external_reference = paymentId`). Si fue pagado → PAID + CashMovement. Si no → sigue PENDING
- **Cuenta corriente (DEFERRED)**: no genera CashMovement. Se crea `Debt` asociado al `Payment`. Al momento de cobrar la deuda, se calcula: `montoPendiente + (montoPendiente * interestRate/100 * mesesTranscurridos)`. El `interestRate` se guarda en `Debt` al crearlo
- El estado CANCELLED es solo manual por el usuario (perdón de deuda)
- Cobro espontáneo: desde la sección Pagos, botón "Nuevo Cobro". Permite elegir cliente registrado o datos ocasionales (nombre, CUIL, dirección). El cliente ocasional genera un `clientId` random con prefijo `"ocasional-"`, NO se persiste en tabla `Client`. Los datos ocasionales van en el campo `notes` del `Payment` como JSON stringificado

### Modelo de caja
- Ingresan a caja: pagos en CASH (automático), pagos MP_QR y TRANSFER confirmados (automático al confirmar)
- NO ingresan a caja: pagos DEFERRED (cuenta corriente)
- Ingresos/egresos manuales: solo piden monto y motivo, crean `CashMovement` sin `paymentId`
- Los movimientos vinculados a un pago NO son editables ni eliminables
- Filtros: por fecha, por tipo (INCOME/EXPENSE), por monto (rango)

### Estructura del PDF factura (compatible AFIP futura)
El PDF debe contener: encabezado con razón social, CUIT, domicilio fiscal, teléfono, logo (si existe en Cloudinary); tipo de comprobante "COMPROBANTE INTERNO X"; número correlativo (usar `Payment.id` últimos 8 chars); fecha de emisión; datos del receptor (nombre/razón social, DNI/CUIL, dirección); tabla de items (descripción, cantidad, precio unitario, subtotal); subtotal, IVA 21% discriminado, total; pie con leyenda "Documento no válido como factura. Uso interno."; espacio reservado para CAE y vencimiento CAE (vacíos por ahora, con label)

### PDF de receta
Contiene: encabezado con datos de la clínica y matrícula del veterinario (campo `veterinarianId` como texto libre por ahora); datos de la mascota y el dueño; fecha; diagnóstico resumido; tabla de prescripciones con: medicamento, dosis, frecuencia, duración, indicación si fue vendido en clínica o si el dueño debe comprarlo; firma y sello (espacio en blanco); leyenda "Válido por 30 días desde la fecha de emisión"

### Subida de imágenes — estrategia más robusta
Usar **base64 directo desde el frontend** → enviar como `multipart/form-data` con `FileInterceptor` de NestJS. El folder de Cloudinary debe ser: `{company.slug}/{client.name.replace(/\s+/g, '_').toLowerCase()}`. Máximo 5 fotos por mascota. Si alguna falla, se reporta con toast de error sin rollback de las que ya subieron. La creación de la mascota en DB se hace primero; si falla la DB, ninguna foto se sube. Si falla una foto, la mascota ya fue creada y se informa cuántas fotos se subieron exitosamente.

La nueva estructura del xlsx es:

Actualizar el método `importFromExcel` para mapear las columnas correctamente:

```typescript
async importFromExcel(companyId: string, buffer: Buffer | Uint8Array) {
  const workbook = new ExcelJS.Workbook();
  const bufferToUse = buffer instanceof Uint8Array ? Buffer.from(buffer) : buffer;
  await workbook.xlsx.load(bufferToUse as any);
  const sheet = workbook.getWorksheet(1);
  const results = { imported: 0, errors: [] as string[] };

  for (let i = 2; i <= sheet.rowCount; i++) {
    const row = sheet.getRow(i);
    const name = row.getCell(1).text?.trim();
    if (!name) continue;

    try {
      const data = {
        brand: row.getCell(2).text || undefined,
        category: row.getCell(3).text || undefined,
        stockUnit: row.getCell(4).text || undefined,
        unitsPerStock: row.getCell(5).value ? Number(row.getCell(5).value) : undefined,
        dispensingUnit: row.getCell(6).text || undefined,
        unit: row.getCell(4).text || undefined, // backward compat
        quantity: row.getCell(7).value !== null ? Number(row.getCell(7).value) : 0,
        unitPrice: row.getCell(8).value !== null ? Number(row.getCell(8).value) : 0,
        salePrice: row.getCell(9).value !== null ? Number(row.getCell(9).value) : undefined,
        minQuantity: row.getCell(10).value !== null ? Number(row.getCell(10).value) : undefined,
        expiresAt: row.getCell(11).text ? new Date(row.getCell(11).text) : undefined,
      };

      const existing = await this.prisma.supply.findFirst({ where: { name, companyId } });
      if (existing) {
        await this.prisma.supply.update({ where: { id: existing.id }, data });
      } else {
        await this.prisma.supply.create({ data: { companyId, name, ...data } });
      }
      results.imported++;
    } catch (e) {
      results.errors.push(`Fila ${i}: ${e.message}`);
    }
  }
  return results;
}
```

## BLOQUE 5 — Consultas Médicas (el bloque más complejo)

### 5.1 Backend: medical-records.service.ts — create con transacción completa

Reemplazar el método `create` para que en una sola transacción atómica:
1. Cree el `MedicalRecord`
2. Cree los `Procedure[]` asociados
3. Cree los `Prescription[]` asociados
4. Descuente el stock de cada `Supply` usado (tanto en procedures como en prescriptions donde `soldInClinic = true`)
5. Cree el `Payment` en estado PENDING con los items calculados
6. Devuelva el record completo con todos los relations

```typescript
async create(companyId: string, dto: CreateMedicalRecordDto) {
  const pet = await this.prisma.pet.findFirst({
    where: { id: dto.petId, companyId },
    include: { client: true },
  });
  if (!pet) throw new NotFoundException('Mascota no encontrada');

  // Calcular items del pago
  const paymentItems = [];
  let totalAmount = 0;

  // Procedures → buscar precio en PriceItem o customPrice
  for (const proc of (dto.procedures || [])) {
    let unitPrice = proc.customPrice || 0;
    if (proc.priceItemId && !proc.customPrice) {
      const pi = await this.prisma.priceItem.findUnique({ where: { id: proc.priceItemId } });
      unitPrice = pi?.price || 0;
    }
    if (proc.supplyId) {
      const supply = await this.prisma.supply.findUnique({ where: { id: proc.supplyId } });
      if (supply?.salePrice && supply?.unitsPerStock) {
        unitPrice = supply.salePrice / supply.unitsPerStock;
      }
    }
    const qty = proc.quantity || 1;
    const total = unitPrice * qty;
    totalAmount += total;
    if (unitPrice > 0) {
      paymentItems.push({
        description: proc.name,
        quantity: qty,
        unitPrice,
        totalPrice: total,
        itemType: proc.supplyId ? 'SUPPLY' : 'PROCEDURE',
      });
    }
  }

  // Prescriptions vendidas en clínica
  for (const pres of (dto.prescriptions || [])) {
    if (!pres.soldInClinic || !pres.supplyId) continue;
    const supply = await this.prisma.supply.findUnique({ where: { id: pres.supplyId } });
    if (!supply) continue;
    const unitIndividual = supply.unitsPerStock ? (supply.salePrice || 0) / supply.unitsPerStock : (supply.salePrice || 0);
    const qty = pres.dispensingQuantity || pres.quantity || 1;
    const total = unitIndividual * qty;
    totalAmount += total;
    paymentItems.push({
      description: `${supply.name} (${qty} ${supply.dispensingUnit || 'u.'})`,
      quantity: qty,
      unitPrice: unitIndividual,
      totalPrice: total,
      itemType: 'SUPPLY',
    });
  }

  // Transacción atómica
  const result = await this.prisma.$transaction(async (tx) => {
    // 1. Crear MedicalRecord
    const record = await tx.medicalRecord.create({
      data: {
        petId: dto.petId,
        visitReason: dto.visitReason,
        diagnosis: dto.diagnosis,
        treatment: dto.treatment,
        observations: dto.observations,
        weight: dto.weight,
        temperature: dto.temperature,
        nextVisitDate: dto.nextVisitDate ? new Date(dto.nextVisitDate) : undefined,
        veterinarianId: dto.veterinarianId,
        date: dto.date ? new Date(dto.date) : undefined,
        procedures: dto.procedures?.length ? {
          create: dto.procedures.map(p => ({
            name: p.name,
            description: p.description,
            priceItemId: p.priceItemId || null,
            supplyId: p.supplyId || null,
            customPrice: p.customPrice,
            quantity: p.quantity || 1,
          })),
        } : undefined,
        prescriptions: dto.prescriptions?.length ? {
          create: dto.prescriptions.map(p => ({
            supplyId: p.supplyId || null,
            medicineName: p.medicineName,
            dose: p.dose,
            frequency: p.frequency,
            duration: p.duration,
            soldInClinic: p.soldInClinic || false,
            quantity: p.quantity || 1,
            dispensingQuantity: p.dispensingQuantity,
            dispensingUnit: p.dispensingUnit,
            doseQuantity: p.doseQuantity,
            doseUnit: p.doseUnit,
          })),
        } : undefined,
      },
      include: {
        procedures: true,
        prescriptions: true,
      },
    });

    // 2. Descontar stock de supplies usados en procedures
    for (const proc of (dto.procedures || [])) {
      if (!proc.supplyId) continue;
      const supply = await tx.supply.findUnique({ where: { id: proc.supplyId } });
      if (!supply) continue;
      // Convertir unidades dispensadas a unidades de stock
      const stockUnitsUsed = supply.unitsPerStock
        ? Math.ceil((proc.quantity || 1) / supply.unitsPerStock)
        : (proc.quantity || 1);
      await tx.supply.update({
        where: { id: proc.supplyId },
        data: { quantity: { decrement: stockUnitsUsed } },
      });
    }

    // 3. Descontar stock de prescriptions vendidas en clínica
    for (const pres of (dto.prescriptions || [])) {
      if (!pres.soldInClinic || !pres.supplyId) continue;
      const supply = await tx.supply.findUnique({ where: { id: pres.supplyId } });
      if (!supply) continue;
      const qty = pres.dispensingQuantity || pres.quantity || 1;
      const stockUnitsUsed = supply.unitsPerStock ? Math.ceil(qty / supply.unitsPerStock) : qty;
      await tx.supply.update({
        where: { id: pres.supplyId },
        data: { quantity: { decrement: stockUnitsUsed } },
      });
    }

    // 4. Crear Payment PENDING
    const payment = await tx.payment.create({
      data: {
        companyId,
        clientId: pet.clientId || null,
        petId: pet.id,
        medicalRecordId: record.id,
        totalAmount,
        status: 'PENDING',
        items: { create: paymentItems },
      },
      include: { items: true },
    });

    // 5. Actualizar medicalRecord con paymentId (relación inversa ya existe via payment.medicalRecordId)

    return { record, payment };
  });

  // 6. Generar PDFs en background (no bloquear la respuesta)
  this.generateAndStorePdfs(result.record.id, result.payment.id, companyId).catch(e =>
    this.logger.error('Error generando PDFs post-consulta', e)
  );

  return result;
}

private async generateAndStorePdfs(recordId: string, paymentId: string, companyId: string) {
  // Delegar a PdfService (inyectarlo en el constructor)
  await Promise.allSettled([
    this.pdfService.generateAndStorePrescription(recordId, companyId),
    this.pdfService.generateAndStoreReceipt(paymentId, companyId),
  ]);
}
```

async function openQRModal(paymentId, totalAmount, onSuccess) {
  // 1. Crear preference en MP
  let initPoint;
  try {
    const pref = await api.post('/mercadopago/preference', {
      paymentId,
      title: 'Servicios veterinarios',
      unitPrice: totalAmount,
      quantity: 1,
    });
    initPoint = pref.initPoint || pref.init_point;
  } catch (e) {
    showToast('Error al generar QR. Contactá al desarrollador.', 'error');
    return;
  }

  // 2. Cargar qrcode.js desde CDN
  if (!window.QRCode) {
    await new Promise((res, rej) => {
      const s = document.createElement('script');
      s.src = 'https://cdn.jsdelivr.net/npm/qrcodejs@1.0.0/qrcode.min.js';
      s.onload = res;
      s.onerror = rej;
      document.head.appendChild(s);
    });
  }

  const COUNTDOWN_SECONDS = 300; // 5 minutos
  let secondsLeft = COUNTDOWN_SECONDS;
  let countdownInterval;
  let pollTimeout;

  openModal({
    title: 'Pagar con QR',
    content: `
      <div style="text-align:center;padding:12px 0;">
        <p style="font-size:13px;color:var(--text-muted);margin-bottom:12px;">
          Escaneá el código con la app de MercadoPago
        </p>
        <div id="qr-canvas" style="display:inline-block;padding:12px;background:white;border-radius:8px;border:1px solid #eee;"></div>
        <div style="margin-top:16px;">
          <div id="qr-countdown" style="font-size:22px;font-weight:700;color:var(--primary);">5:00</div>
          <div style="font-size:12px;color:var(--text-muted);">Tiempo de validez</div>
        </div>
        <div id="qr-status" style="margin-top:12px;font-size:13px;color:var(--text-muted);">Esperando pago...</div>
      </div>
    `,
    actions: [
      {
        label: 'Cancelar (quedará pendiente)',
        class: 'btn-secondary',
        onClick: () => {
          clearInterval(countdownInterval);
          clearTimeout(pollTimeout);
          closeModal();
        }
      }
    ]
  });

  // Generar QR
  new window.QRCode(document.getElementById('qr-canvas'), {
    text: initPoint,
    width: 200,
    height: 200,
    correctLevel: window.QRCode.CorrectLevel.M,
  });

  // Countdown
  countdownInterval = setInterval(() => {
    secondsLeft--;
    const m = Math.floor(secondsLeft / 60);
    const s = secondsLeft % 60;
    const el = document.getElementById('qr-countdown');
    if (el) el.textContent = `${m}:${s.toString().padStart(2, '0')}`;

    if (secondsLeft <= 0) {
      clearInterval(countdownInterval);
      clearTimeout(pollTimeout);
      // Verificar pago al expirar
      checkPaymentStatus();
    }
  }, 1000);

  // Poll periódico cada 10s durante los 5 minutos
  const pollInterval = setInterval(async () => {
    if (secondsLeft <= 0) { clearInterval(pollInterval); return; }
    const paid = await verifyPayment();
    if (paid) {
      clearInterval(pollInterval);
      clearInterval(countdownInterval);
    }
  }, 10000);

  async function verifyPayment() {
    try {
      const payment = await api.get(`/payments/${paymentId}`);
      if (payment.status === 'PAID') {
        const statusEl = document.getElementById('qr-status');
        if (statusEl) statusEl.textContent = '✓ Pago confirmado';
        showToast('Pago exitoso', 'success');
        setTimeout(() => { closeModal(); onSuccess?.(); }, 1500);
        return true;
      }
    } catch (e) { /* ignorar */ }
    return false;
  }

  async function checkPaymentStatus() {
    const statusEl = document.getElementById('qr-status');
    if (statusEl) statusEl.textContent = 'Verificando estado del pago...';
    const paid = await verifyPayment();
    if (!paid && statusEl) statusEl.textContent = 'QR vencido. El pago quedó pendiente.';
  }
}

async function openDebtPaymentModal(debt, onSuccess) {
  const now = new Date();
  const createdAt = new Date(debt.createdAt);
  const monthsElapsed = Math.max(0, (now - createdAt) / (1000 * 60 * 60 * 24 * 30));
  const pendingAmount = debt.amount - (debt.paidAmount || 0);
  const interest = debt.interestRate ? pendingAmount * (debt.interestRate / 100) * monthsElapsed : 0;
  const totalWithInterest = pendingAmount + interest;

  openModal({
    title: 'Pagar deuda',
    content: `
      <div style="display:flex;flex-direction:column;gap:12px;">
        <div style="display:grid;grid-template-columns:1fr 1fr;gap:12px;padding:12px;background:var(--bg-secondary);border-radius:8px;">
          <div><div style="font-size:12px;color:var(--text-muted);">Deuda original</div><div style="font-weight:600;">${formatCurrency(debt.amount)}</div></div>
          <div><div style="font-size:12px;color:var(--text-muted);">Saldo pendiente</div><div style="font-weight:600;">${formatCurrency(pendingAmount)}</div></div>
          ${debt.interestRate ? `<div><div style="font-size:12px;color:var(--text-muted);">Interés (${debt.interestRate}%/mes × ${monthsElapsed.toFixed(1)} meses)</div><div style="font-weight:600;color:var(--danger);">+${formatCurrency(interest)}</div></div>` : ''}
          <div><div style="font-size:12px;color:var(--text-muted);">Total a pagar</div><div style="font-size:20px;font-weight:700;">${formatCurrency(totalWithInterest)}</div></div>
        </div>
        <div>
          <label class="form-label">Monto a pagar ahora</label>
          <input type="number" id="debt-pay-amount" class="input" value="${totalWithInterest.toFixed(2)}" min="1" max="${totalWithInterest.toFixed(2)}">
          <div style="font-size:12px;color:var(--text-muted);margin-top:4px;">Podés pagar un monto parcial.</div>
        </div>
      </div>
    `,
    actions: [
      { label: 'Cancelar', class: 'btn-secondary', onClick: closeModal },
      {
        label: 'Proceder al pago',
        class: 'btn-primary',
        onClick: () => {
          const amount = Number(document.getElementById('debt-pay-amount')?.value);
          if (!amount || amount <= 0) { showToast('Ingresá un monto válido', 'error'); return; }
          closeModal();
          // Actualizar el pago vinculado con el monto parcial o total
          openPaymentModal(debt.paymentId, amount, async () => {
            // Si es pago total, marcar deuda como PAID
            if (amount >= totalWithInterest - 0.01) {
              await api.patch(`/debts/${debt.id}`, { status: 'PAID', paidAt: new Date().toISOString() });
            } else {
              // Pago parcial: actualizar amount restante
              await api.patch(`/debts/${debt.id}`, { amount: pendingAmount - amount });
            }
            onSuccess?.();
          });
        }
      }
    ]
  });
}
