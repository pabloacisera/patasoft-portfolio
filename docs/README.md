# docs/ — Documentación para Humanos

Mapa de navegación de la documentación de PataSoft.

## Archivos en esta carpeta

| Archivo | Para quién | Qué contiene |
|---|---|---|
| `ARCHITECTURE.md` | Desarrolladores | Diagramas del sistema, stack, módulos |
| `DECISIONS.md` | Todo el equipo | ADRs (decisiones técnicas) + FIX log (correcciones documentadas) |
| `FLOWS.md` | Desarrolladores | Flujos detallados del negocio |
| `documents_flow.md` | Desarrolladores | Flujo de generación de documentos (PDF, Excel) |
| `payment_mp.md` | Desarrolladores | Integración con MercadoPago |
| `TECHNICAL_GUIDE.md` | Desarrolladores | Guía técnica de desarrollo |
| `diagrams/` | Desarrolladores | Diagramas complementarios |

## Cómo navegar el proyecto

```
📄 README.md              → Quick start (instalación local)
📂 docs/                  → Documentación para humanos (estás aquí)
📂 agent/                 → Documentación para agentes de IA
📄 TASKS.txt              → Backlog activo de tareas pendientes
📄 .env.example           → Variables de entorno requeridas
📄 render.yaml            → Configuración de deploy (Render)
```

## Enlaces rápidos

- Ver el backlog activo: `TASKS.txt` en la raíz
- Entender decisiones pasadas: `docs/DECISIONS.md`
- Diagrama arquitectónico: `docs/ARCHITECTURE.md`
- Estado actual para IA: `agent/CONTEXT.md`
